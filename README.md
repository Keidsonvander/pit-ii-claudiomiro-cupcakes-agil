# PIT II — Cupcakes Gourmet | Claudiomiro Monteiro Junior

Projeto acadêmico de **Claudiomiro Monteiro Junior — RGM 33634254**, desenvolvido como continuidade da PIT I.

## Contexto
A PIT I trabalhou o desenvolvimento de uma solução para uma loja de cupcakes gourmet, considerando vendas online, pedidos, pagamentos, entrega e organização do fluxo de compra.

## Base utilizada
Foram considerados:
- requisitos;
- histórias de usuário;
- backlog de produto;
- regras de negócio;
- critérios de aceitação;
- experiência do usuário;
- prototipação e organização das funcionalidades.

## Objetivo
Dar continuidade ao planejamento da PIT I e transformar os requisitos e funcionalidades definidas em uma solução funcional e testável.

## PIT II
Nesta etapa será implementada uma aplicação web responsiva representando o fluxo principal de compra de cupcakes, incluindo catálogo, carrinho, dados do cliente, pagamento, entrega, confirmação e acompanhamento do pedido.
